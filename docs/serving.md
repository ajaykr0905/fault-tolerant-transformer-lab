# Serve the recovered CPU prototype locally

After installing the locked environment, create a fresh demo checkpoint:

```bash
uv run --frozen fttl-demo --output artifacts/serving-demo-001
uv run --frozen fttl-serve \
  --config artifacts/serving-demo-001/config.json \
  --checkpoint artifacts/serving-demo-001/run/recovered/checkpoints \
  --dataset-manifest artifacts/serving-demo-001/dataset/manifest.json \
  --port 8080 --request-timeout-seconds 5 --max-request-bytes 16384
```

The command stays in the foreground. It verifies the trusted checkpoint, dataset,
tokenizer and experiment identity, reconstructs frozen FP32 CPU weights, and binds
only `127.0.0.1`. Startup prints one flushed JSON readiness message containing the
actual port and inference receipt. Use `--port 0` to request an available port and
read the reported URL; never assume that zero itself is a connectable port.
Invalid controls, missing/corrupt checkpoints or occupied ports exit before readiness.
No data download, API key or GPU is needed after environment and dataset setup.

In another terminal:

```bash
curl --fail http://127.0.0.1:8080/health
curl --fail http://127.0.0.1:8080/generate \
  -H 'Content-Type: application/json' \
  --data '{"prompt":"Hello","max_new_tokens":8,"method":"sample","top_k":8,"seed":23}'
```

`/health` returns readiness, the original inference receipt and resource limits.
`/generate` returns that receipt alongside the authoritative integer-token report.
The prompt is UTF-8 text; no generated bytes are presented as invented readable text.
Optional controls are `max_new_tokens`, `method`, `temperature`, `top_k`, `seed`
and `stop_token_id`, with the same semantics as [local generation](generation.md).
The byte vocabulary includes EOD token 256, which is not a byte. Identical sampled
requests replay within the same model state and CPU software environment.

Requests require one valid `Content-Length` and JSON UTF-8 content type. Transfer
encoding, duplicate or unknown JSON fields, non-finite numbers and invalid controls
are rejected. Default request-body cap is 16 KiB, configurable up to 64 KiB; prompt
and generation caps remain 4096 UTF-8 bytes and 256 new tokens. Connections close
after each response. If weights, runtime configuration, training modes or freezing
drift, readiness is revoked and generation fails with HTTP 503. Unexpected backend
failures are generic HTTP 500 responses without filesystem paths or tracebacks.

Press Ctrl-C to stop. On Linux/macOS, SIGTERM also closes the foreground server
cleanly; signal handlers are restored on exit. Do not detach it as a persistent
service, expose it through a public tunnel, or replace the loopback bind.

This is a single-threaded, unauthenticated local prototype. Socket timeouts limit
idle waits, not total request wall time: a slow local client can occupy the only
handler. Loopback is not isolation from other local users. There is no public-network
authentication, CORS integration, KV cache, concurrent model execution, latency SLA
or production-readiness claim. Tiny random-model output does not establish language
quality. Checkpoint integrity hashes are not authentication; use trusted local artifacts.
